# 0-FemasLaravel
 sitio web de femas

## INTRODUCCION
 creacion del preyecto

Crea la ultma version de laravel:

    composer create-project laravel/laravel femas

Te Lleva a la carpeta

    cd femas

Instalamos  tailwind

    npm install
    
    npm run dev

arracamos el proyecto

    php artisan serve
